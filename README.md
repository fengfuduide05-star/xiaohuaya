# 小画芽 · AI 辅助美术教学点评工具

面向少儿美术机构老师的课后点评场景：老师上传学生作品，AI 生成画面观察与可编辑点评草稿，
老师核对确认后生成家长报告，并附带结构练习建议。

**在线体验**：打开 `index.html`（或访问本站首页）即可点击体验完整流程。

## 核心设计

- **不做的事**：不打分、不排名、不推测天赋、无历史作品不判断进步。
- **双状态机制**：点评草稿自动保存，家长报告只采用老师确认过的版本，改稿不覆盖已发布报告。
- **能力边界**：AI 只描述画面里能看见的内容，教学判断始终由老师做出。

## 文件

- `index.html` — 单文件可点击原型（无需安装依赖，建议 Chrome / Edge / Safari 近期版本）
- `小画芽-产品需求文档-v1.1.pdf` — 13 页需求文档，定义 F01–F18 共 18 项功能
- 另附功能与验收清单（18 项功能 / 36 项验收用例）

## 说明

本原型为离线演示版本：人物、作品与数据均为虚构示例；未接入真实 AI、账号体系、服务器存储与消息发送。
原型验收通过不等同于生产上线验收。
